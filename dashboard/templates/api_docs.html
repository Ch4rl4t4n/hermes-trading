Hermes API Documentation

Elite tier — REST API

Authentication

API kľúč vygeneruješ v nastaveniach dashboardu (Settings). Kľúč uvidíš len raz.

curl -H "Authorization: Bearer hk_live_xxx" \
  https://app.letagentscook.lol/v1/agents

Rate Limits

Limit je 60 requestov/minútu na každý API kľúč.

Response hlavičky: X-RateLimit-Limit, X-RateLimit-Remaining, X-RateLimit-Reset

Endpoints

GET/v1/agents — zoznam user + subscribed agentov
GET/v1/agents/:id — detail agenta + posledných 10 obchodov
GET/v1/agents/:id/pnl?period=today|week|month|all — P&L štatistiky
GET/v1/agents/:id/backtest — posledný backtest výsledok
GET/v1/marketplace — approved marketplace listingy (verejné)
POST/v1/agents/:id/pause — pause user agenta
POST/v1/agents/:id/resume — resume user agenta
POST/v1/agents/:id/config — update config (SL, position size, max daily trades)
{
  "data": { "...": "..." },
  "timestamp": "2026-05-05T14:00:00+00:00"
}

Error Codes

  • 401 Unauthorized — chýba/neplatný API kľúč
  • 403 Forbidden — tier bez API prístupu
  • 429 Too Many Requests — prekročený rate limit
  • 500 Internal Error — interná chyba servera
{
  "error": "Unauthorized",
  "message": "Provide API key in Authorization header",
  "code": 401
}

Code Examples

Python (requests)
import requests

headers = {"Authorization": "Bearer hk_live_xxx"}
r = requests.get("https://app.letagentscook.lol/v1/agents", headers=headers, timeout=30)
print(r.status_code, r.json())
JavaScript (fetch)
const r = await fetch("https://app.letagentscook.lol/v1/agents", {
  headers: { Authorization: "Bearer hk_live_xxx" }
});
const data = await r.json();
console.log(r.status, data);
